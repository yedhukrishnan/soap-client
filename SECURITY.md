# Security

Thanks for helping keep SOAP Client safe.

If you notice something security-related, please share it privately rather than in a public issue:

- **GitHub:** [report it privately](https://github.com/yedhukrishnan/soap-client/security/advisories/new)
  (Security tab → *Report a vulnerability*)
- **Email:** dev@yedhu.me

It helps to include the app version (shown in *About SOAP Client*) and the steps to reproduce.
I'll get back to you within a few days.

For anything else, bugs, questions and ideas are welcome as regular
[issues](https://github.com/yedhukrishnan/soap-client/issues).
